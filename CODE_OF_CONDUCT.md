# Community code of conduct

Treat people with respect, welcome questions, credit contributions, and discuss ideas using evidence. Give constructive feedback and consider differing experience levels and perspectives. Harassment, threats, discriminatory language, personal attacks, and publishing another person's private information are unacceptable.

Project maintainers may remove harmful content, request changes, or limit participation when necessary. Report concerns privately to a maintainer through the repository hosting platform's private reporting features when available. Avoid posting personal details in public issues. Maintainers should handle reports confidentially and fairly, and explain decisions to affected contributors when appropriate.
