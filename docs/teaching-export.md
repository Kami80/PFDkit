# Teaching examples and academic export

PFDkit keeps engineering data, diagram appearance and teaching content in the same editable document. Export figures from **Export figure**; native JSON always saves the complete document. Presentation inspection uses a temporary view and does not rewrite engineering values.

## Choosing content and size

Choose the full PFD, selected equipment/streams, a process section, or an equipment detail. Selecting a section expands its descendant equipment. A selected stream includes endpoint symbols; a section figure contains its internal streams. Targeted visible annotations follow the exported objects; untargeted notes are included only near a selected figure. Hidden annotations and private lecture notes are excluded. Equipment detail includes visible annotations targeted to that equipment when the annotation checkbox is enabled.

The same SVG scene supplies SVG, PNG and PDF, including titles, legends, stream labels and educational annotation provenance. Long labels expand the scene bounds. Unknown operating values remain unknown, and no export performs a process calculation.

| Preset            | Physical page size                | Use                                                           |
| ----------------- | --------------------------------- | ------------------------------------------------------------- |
| Drawing bounds    | Natural scene units               | Detailed equipment and large diagrams without reducing labels |
| 16:9              | 960 × 540 pt                      | Widescreen slides                                             |
| 4:3               | 720 × 540 pt                      | Standard slides                                               |
| A4                | 595.276 × 841.89 pt               | Portrait paper                                                |
| Letter            | 612 × 792 pt                      | Portrait paper                                                |
| Scientific figure | 252.283 × 181.417 pt (89 × 64 mm) | Single-column figure; prefer a concise selected section       |
| Custom            | 72–14,400 pt per side             | Poster, tall column detail or an exact publication size       |

**72 points = one inch.** Page margins are in points. The scene fits inside the margins with its aspect ratio preserved and is centered; content is never cropped or stretched. SVG paper/slide presets declare physical point units. PNG adds its independent pixel dimensions (64–8192 px per side, at most 32 million pixels) and preserves the page ratio inside those pixels. Transparent export omits the page/diagram background; intentional equipment and annotation fills remain.

Read the preview at the intended print or display size. The dialog warns when the smallest declared font becomes less than 6 pt after fitting to the selected page; this estimate does not block downloading. A 100-stage column keeps every stage at readable spacing in its natural detail scene; reducing the whole column to A4 or a small scientific panel also reduces all text. Choose a tall custom page, drawing bounds, a selected section or a simpler figure when needed. No automatic multi-page tiling is performed.

## PDF text and vector handling

PDF is a downloadable file generated locally using jsPDF and svg2pdf.js. Supported SVG paths, shapes, markers and text remain vector content. No remote rendering service, account or paid API is required. Standard Helvetica, Times and Courier map from the supported diagram font choices; fonts are not fetched from the network or silently substituted with arbitrary system fonts. Common arrows, typographic quotes and dashes use explicit readable ASCII equivalents in PDF. Latin text and ordinary accented Latin characters are supported. Unsupported non-Latin glyphs stop export with the character and Unicode code point in the error; use SVG or PNG to preserve that text, or revise the PDF labels. SVG/PNG retain the original text and use installed font fallbacks.

PDF viewers may show transparent pages as white. PDF conversion omits text halo strokes because svg2pdf does not support SVG text paint order; stream label fills remain visible and selectable. SVG and PNG retain the halos. PDF export is a single page with a maximum side of 14,400 pt; choose a preset before exporting an unusually large scene. These PDFs are publication figures, not a tagged accessible-document or PDF/A implementation. SVG has title/description text; the editable JSON retains all content, references and lecture notes.

## Visual presets

**Engineering Classic** uses restrained neutral strokes. **Academic Colorful** distinguishes equipment classes with colorblind-conscious colors. **Minimal Scientific** uses fine grayscale strokes for papers. **Presentation** uses stronger colors and larger default text/strokes when no explicit sizing overrides have been saved. Energy streams remain dashed in every theme; labels and distinct symbols supplement color. Existing per-object color, label and sizing overrides survive a preset change. Adjust figure font size and line width explicitly when preparing a specific paper or slide.

## Reviewed teaching documents

Open **Local projects → Import JSON**, or use the example chooser when available. The examples are generated deterministically by `scripts/teaching_examples.py` through the contract generator. Each file includes original-content attribution, an MIT license, review date/scope, source links, conceptual annotations, two lecture steps and explicit illustrative-value status. Each first inlet has an arbitrary illustrative 25 °C value for a unit-entry exercise; other stream temperatures remain unknown. A visible annotation and stream metadata state that this value is neither measured nor calculated. Stage/pass counts are illustrative configuration rather than solved engineering results. Structural validation passes; deliberate unconnected draft ports may produce warnings.

The original explanations and art are reusable under MIT. References support the stated principles; their copyrighted diagrams and prose are not copied or relicensed by these examples. Review means structural/terminology/scope review, not a certified process-design, performance or safety review.

Reference links were checked on 2026-10-28. ETH Hyper-TVT is an archived teaching resource; its examples of multiple feeds support the lesson's terminology. The AFDC/Wisconsin resources support the distinction between fermentation broth and purified ethanol, CDC supports the omitted downstream water-treatment steps, and DOE supports separate electrolysis product circuits and heat-transfer principles. None supplies the arbitrary 25 °C exercise value or calculated conditions for these schematics.

## Reproducible verification

Run the standard repository checks plus `apps/web/src/lib/explorers.test.ts` and `apps/web/src/lib/export-academic.test.ts`. Tests cover dynamic stream references, reduced stage counts, retained unknowns, history, representative pass configurations, dense feed labels, escaped text, physical preset margins, origin translation, annotation scope, transparency, deliberate font errors, all five example contracts and theme overrides. Browser tests exercise actual downloads and inspection navigation. Representative PDF/SVG/PNG visual inspection and the final milestone evidence are recorded in [the M3 acceptance record](m3-acceptance.md).

For a new renderer or configuration model, follow [the explorer authoring guide](explorer-authoring.md). Imported documents contain declarative data only; executable extensions are reviewed application code.
